# nobre-persianas

Landing page de uma loja de persianas (Next.js + Tailwind + shadcn/ui).

Site institucional de uma loja de persianas e cortinas, focado em levar o visitante ao orçamento.

## Stack
Next.js (App Router), React, TypeScript, Tailwind CSS, shadcn/ui e Lucide.

## Rodar
```bash
npm install
npm run dev      # http://localhost:3000
```
